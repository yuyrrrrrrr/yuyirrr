# 首页 3D 长胶卷改造说明

## 修改文件

- `src/components/FilmGallery.astro`：胶卷结构、交互、详情层数据绑定
- `src/scripts/film-reel.ts`：新增 Three.js 连续曲面胶卷场景
- `src/styles/stage.css`：WebGL 舞台、叠加标题、回退布局与响应式样式
- `src/data/film.ts`：更新 16:9 剧照清单
- `public/images/film/05-api.jpg`：替换校园活动报名 API 的裁切图
- `tests/site.spec.ts`：新增 3D 胶卷逐项打开详情的测试
- `package.json` / `package-lock.json`：加入 Three.js 与类型声明
- `README.md`：补充 3D 胶卷说明

## 问题原因

1. **平面卡片感**：桌面端原实现由多个独立的 DOM 卡片组成，每张卡片只根据自己的横向偏移设置 `rotateY / translateZ`。卡片之间存在独立的边框和较大间距，无法形成连续的胶片曲面。
2. **间距过大**：卡片本身有内边距和圆角，外层轨道还有额外 `gap`，画面之间被多层深色区域隔开，视觉上更像展示板。
3. **点击不一致**：左右切换按钮曾经覆盖在两侧画面上方，挡住了部分点击区域；同时详情依赖固定的卡片结构，边缘画面在 3D 变换下的点击层级不稳定。

## 修复方式

### 连续胶片

- 使用 Three.js 构建一条连续的弯曲胶片：
  - 画面、片基、上下片边和齿孔共用同一条 `z = cos(x)`、`y = 1 - cos(x)` 空间轨迹。
  - 每个画面在横向被细分为多段网格，因此画面本身会随胶片弯曲，而不是整张平面卡片单独旋转。
  - 片基和齿孔延伸到所有画面之外，作为首尾片头/片尾，画面之间只保留很窄的胶片间隙。
  - 齿孔纹理由连续的 UV 映射到弯曲片边上，跟随胶片一起起伏。
- 通过透视相机、逐画面明暗和侧边压暗强化中心画面；滚动时整条胶片沿同一轨迹移动。
- 相机根据视口宽高自动计算可视宽度和画面比例，并为标题预留底部空间；短窗口会自动缩小胶片，避免标题与底部指示器重叠。
- 添加轻微的胶片颗粒、暗角和低对比度地面光晕，保持原有暗色电影风格。

### 回退方案

- 移动端、`prefers-reduced-motion`、WebGL 不可用或脚本加载失败时，继续使用原来的静态连续胶卷布局。
- 禁用 JavaScript 时仍显示完整作品带，作品链接直接进入项目详情页。

### 点击与详情

- 导航箭头移出画面覆盖层，放到首页底部 HUD，不再遮挡两侧作品。
- 桌面端通过 Three.js 射线检测直接命中每张弯曲画面，使用命中画面的索引打开对应项目。
- 每个画面和每个叠加标题都携带独立的项目数据与 `data-index`；详情层完全根据被点击元素的数据填充，不再复用第一份数据。
- 保留原有详情层组件能力：项目名称、封面、简介、类别、时间、角色、技术栈、截图、Demo/仓库链接和完整案例入口。
- 支持关闭按钮、点击遮罩、`Escape` 关闭；关闭时锁定滚动，关闭后恢复访问前的胶卷位置。

## 验证结果

- `npm run build` 通过（Astro 检查、静态构建、简历 PDF）。
- Playwright 共 11 项测试全部通过，包括：
  - 3D 胶卷中 5 个画面逐个点击打开对应详情；
  - 右侧相邻画面独立点击；
  - 键盘切换后打开新作品详情；
  - 关闭详情后滚动位置不变；
  - 禁用 JavaScript 时作品带仍可浏览；
  - 移动端、平板、桌面无横向溢出；
  - 首页及内容页 Axe 可访问性扫描无违规。
- 人工截图检查了 1440×900、1920×1080、768×1024、1280×700、1280×600 和 390×844 视口。
